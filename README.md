# SEO GEO Skill

Advanced SEO and geographic intelligence for The GEO Lab suite.

## Features

- **Production-tested** SEO tools with [GEO-native brand citation tracking](https://brand-citation.thegeolab.net)
- Keyword research and analysis
- Competitor tracking and gap analysis
- Location-based SEO optimization
- SERP monitoring and rank tracking

## Installation

```bash
npm install @thegeolab/seo-geo-skill
```

## Usage

```javascript
const seoSkill = require('@thegeolab/seo-geo-skill');

// Analyze a domain
seoSkill.analyze({
  domain: 'example.com',
  includeCompetitors: true,
  geographic: true
});
```
